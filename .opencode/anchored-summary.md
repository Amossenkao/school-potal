- **AddUsers enrollment-year bug — ROOT CAUSE + FIXED**: `buildUserData` in `app/api/users/route.ts` used `const academicYear = getAcademicYear()` (line 479) which is **date-based**: `getAcademicYear()` (line 127) returns `${currentYear}-${currentYear+1}` when `currentMonth >= 7`, else `${currentYear-1}-${currentYear}`. On Aug 2026 that yields `2026-2027`, completely ignoring the form's `enrollmentYear`. Fix: `const academicYear = userData.enrollmentYear || getAcademicYear();` — now the student's `enrollmentYear` field AND its single `academicYears: [{ year, classId, className }]` entry (lines 522-528) use the form-selected year. The frontend (`AddUsers.tsx`) was already correct (defaults to `school.identity.currentAcademicYear`, sends `enrollmentYear` in the POST payload).
