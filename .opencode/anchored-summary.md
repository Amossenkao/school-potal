## Objective
- Fix missing/live parent updates when a student is created/assigned to a parent: POST `/api/users` (AddUsers) must notify the linked parent; EditUserModal assignment already reaches the parent via Ably but the parent's store doesn't apply it live (stale until re-login).
- Include parents in the bootstrap `users` payload so admin rosters and local searches have them.
- Make user searches local-first: AddUsers parent search and EditUserModal parent/student searches query the local `schoolStore` roster first, falling back to `/api/users` only when no local matches.
